# บทที่เขียนไว้แล้ว

บทความรู้รอบตัว 16 เรื่อง ผ่าน schema และยาว 33–39 วินาทีเมื่อลงเสียงด้วย `th-TH-NiwatNeural` (วัดจริง 2026-11-12)
ยังไม่ได้ปรับให้เข้ากับแนวช่อง (`channel.niche`) เพราะยังไม่ได้กำหนด ถ้าแนวช่องไม่ใช่ความรู้รอบตัว ให้ใช้เป็นตัวทดสอบระบบ

ใช้งาน (ไม่ต้องมีคีย์ Gemini):

```
uv run autovideo new --script drafts/honey.json
```

งานจะไปหยุดรอยืนยันบทเหมือนบทที่ AI เขียน กด "แก้ไข" หรือ "เขียนใหม่" ได้ตามปกติ (สองปุ่มนี้ต้องใช้ Gemini)
ระวัง: ระบบจำกัดไม่เกิน `limits.max_jobs_per_day` งานต่อวัน

| ไฟล์ | หัวข้อ | ชื่อคลิป |
|---|---|---|
| `banana.json` | กล้วยมีกัมมันตรังสี | กล้วยมีกัมมันตรังสี จริงหรือมั่ว |
| `cat_landing.json` | ทำไมแมวตกจากที่สูงแล้วลงด้วยเท้า | แมวตกตึก ทำไมถึงลงด้วยเท้าเสมอ |
| `egg_float.json` | ทดสอบไข่เก่าด้วยน้ำ | ไข่ลอยน้ำ แปลว่าอะไร |
| `honey.json` | ทำไมน้ำผึ้งไม่บูด | อาหารที่เก็บได้เป็นพันปี อยู่ในครัวคุณแล้ว |
| `leaf_color.json` | ทำไมใบไม้เปลี่ยนสี | ใบไม้ไม่ได้เปลี่ยนเป็นสีเหลือง มันเหลืองอยู่แล้ว |
| `lightning.json` | ฟ้าแลบก่อนฟ้าร้อง | นับวินาทีหลังฟ้าแลบ รู้เลยว่าพายุอยู่ไกลแค่ไหน |
| `moon_face.json` | ดวงจันทร์หันด้านเดียวเข้าหาโลก | ทำไมเราเห็นดวงจันทร์แค่ด้านเดียว |
| `octopus.json` | ความแปลกของปลาหมึกยักษ์ | สัตว์ที่มี 3 หัวใจ และเลือดสีฟ้า |
| `onion.json` | ทำไมหั่นหัวหอมแล้วน้ำตาไหล | หั่นหอมแล้วน้ำตาไหล แก้ได้ง่ายกว่าที่คิด |
| `polar_bear.json` | หมีขั้วโลกผิวสีดำ | หมีขั้วโลกไม่ได้ขาวอย่างที่คิด |
| `sea_salt.json` | ทำไมน้ำทะเลเค็ม | น้ำฝนจืด แม่น้ำจืด แล้วทำไมทะเลเค็ม |
| `shark_tree.json` | ฉลามมีมาก่อนต้นไม้ | ฉลามอยู่บนโลกมานานกว่าต้นไม้ |
| `sky.json` | ทำไมท้องฟ้าเป็นสีฟ้า | ทำไมท้องฟ้าเป็นสีฟ้า แต่ตอนเย็นเป็นสีส้ม |
| `sleep.json` | ประโยชน์ของการนอนหลับ | นอนน้อยคืนเดียว สมองพังกว่าที่คิด |
| `spicy.json` | ทำไมกินเผ็ดแล้วรู้สึกร้อน | พริกไม่ได้ร้อน แต่สมองคุณถูกหลอก |
| `wrinkly_fingers.json` | ทำไมนิ้วเหี่ยวเวลาแช่น้ำ | แช่น้ำนานแล้วนิ้วเหี่ยว ร่างกายตั้งใจทำ |
